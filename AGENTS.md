# 🤖 Мультиагентная система JLPT Dokkai Master

В проекте настроена специализированная мультиагентная система, состоящая из двух экспертных агентов:
1. **`@jlpt-expert`** — Эксперт-методолог экзамена JLPT (N5–N1), лингвист и преподаватель японского языка.
2. **`@senior-dev`** — Senior Software Engineer (Python, FastAPI, TypeScript/JS, архитектура, безопасность Anti-Cheat, тесты).

## 👥 Роли и зоны ответственности

| Агент | Роль | Ключевые задачи |
| :--- | :--- | :--- |
| **`@jlpt-expert`** | Методолог JLPT, лингвист | • Грамматический анализ (文法) уровней N5–N1<br>• Проверка точности фуриганы (`<ruby>漢字<rt>かんじ</rt></ruby>`)<br>• Методика дистракторов (почему 3 варианта ложные, а 1 верный)<br>• Разметка ключевых доказательств (`evidence_span_id`)<br>• Адаптация статей NHK World под уровни экзамена |

## 🚀 Способы использования

### Вариант 1: Использование в чате AI (через упоминания `@`)

#### 1. Только Лингвист (`@jlpt-expert`):
Используйте, когда вам нужен разбор японского текста, объяснение грамматических ловушек или генерация контента заданий:
```text
@jlpt-expert Разбери текст уровня N3 про экологию, выдели грамматические конструкции и подготовь 2 экзаменационных вопроса с 4 вариантами ответа и дистракторами.
```

#### 2. Только Разработчик (`@senior-dev`):
Используйте для технической реализации, рефакторинга кода, написания эндпоинтов или устранения багов:
```text
@senior-dev Проверь эндпоинты в main.py на соответствие протоколу Anti-Cheat и запусти тестовый сьют test_api.py.
```

#### 3. Совместная работа (Dual Agent Orchestration):
Объединяйте обоих агентов в одном запросе для сквозных образовательных фичей:
```text
Нужно добавить новый раздел заданий по поиску информации (N3 info_search):
1. @jlpt-expert подготовит текст расписания с японской разметкой ruby-фуриганы, вопросами, ловушками и span-доказательствами.
2. @senior-dev интегрирует полученные данные в seed.py, добавит Pydantic-схему и проверит прохождение тестов test_api.py.
```

### Вариант 2: Запуск через консольный скрипт (`run_agents.py`)

В корне проекта есть CLI-менеджер [`run_agents.py`](file:///c:/Users/wawil/OneDrive/Рабочий%20стол/Dokkai/run_agents.py).

#### Интерактивный запуск (меню выбора):
```bash
python run_agents.py
```
Откроется интерактивное меню:
```text
Выберите режим запуска мультиагентной системы:
  [1] Запустить только @jlpt-expert (Лингвист-методолог JLPT)
  [2] Запустить только @senior-dev (Senior Software Engineer)
  [3] Запустить обоих агентов одновременно (Dual Orchestrator)
  [4] Быстрая самодиагностика проекта и автотесты
  [0] Выход
```

#### Запуск с флагами командной строки:
```bash
# Запуск только эксперта по японскому языку
python run_agents.py --expert -t "Анализ текста NHK N2"
# или короткий флаг:
python run_agents.py -e

# Запуск только Senior-разработчика (с автопроверкой тестов и синтаксиса)
python run_agents.py --dev -t "Оптимизация запросов каталога"
# или короткий флаг:
python run_agents.py -d

# Совместный запуск (Оркестратор: Лингвист + Разработчик)
python run_agents.py --both -t "Добавление новых архивных текстов JLPT"
# или короткий флаг:
python run_agents.py -b

# Быстрая самодиагностика целостности проекта (Синтаксис + Anti-Cheat + Тесты)
python run_agents.py --check
```
