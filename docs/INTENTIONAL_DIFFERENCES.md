## 🔎 Шаг 11d — серверное перемешивание вариантов ответов

| № | Отличие | Причина |
| :-: | :--- | :--- |
| **29** | Варианты перемешиваются на сервере: порядок = сортировка по `HMAC(SHUFFLE_SECRET, user_id\|text_id\|epoch\|question_id\|option_id)`. `epoch` = число уже завершённых попыток пользователя по тексту (`UserTextState.attempts_count`): порядок новый для каждой попытки, но одинаков при обновлении страницы, рестарте бэкенда и в разборе этой попытки.
