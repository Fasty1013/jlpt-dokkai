# 🧭 Матрица тестового покрытия (QA Coverage Matrix)

Документ определяет полную матрицу состояний, устройств, браузерных движков, тем оформления и сетевых профилей для регулярного и регрессионного тестирования приложения JLPT Dokkai Master.

---

| Экран / Компонент | Гость (Guest) | Авторизован (Dev-Auth) | Состояние загрузки (Loading) | Пустое состояние (Empty) | Ошибка сети / API (Error) | Офлайн (Offline) | Пробуждение сервера (Cold Start) |
| :--- | :---: | :---: | :---: | :---: | :---: | :---: | :---: |

| **Мой словарь («Notebook»)** | ✅ Локальный список | ✅ Облачный бэкап | Загрузка слов | «Словарь пуст» | — | Полный доступ | Работает автономно |

> [!IMPORTANT]
> **Ограничение Prod (Режим «Только чтение»):**  
> На `prod_url` строго запрещены операции записи: `POST /api/stream/complete`, `POST /api/stream/retry`, `POST /api/texts/{id}/report`, `POST /api/admin/*`.  
> На `prod_url` тестируются: холодный старт, отображение интерфейса, чтение текстов, Wizard без отправки, мобильная адаптивность, шрифты, фуригана, темы, Lighthouse, axe-core и отсутствие утечек Anti-Cheat. Все сценарии изменения данных выполняются исключительно на `localhost`.

## 3. Матрица браузерных движков (Engines)

| Движок | Платформа в тестах | Эмулируемый браузер | Специфика рендеринга японского языка |
| :--- | :--- | :--- | :--- |
| **Chromium** | Windows / Linux | Google Chrome, Edge | Базовый рендеринг, поддержка всех спецификаций CSS Grid/Flex, Web Speech API. |
| **Firefox** | Windows / Linux | Mozilla Firefox | Особенности расчета высоты тегов `<ruby>` и `<rt>`, поведение `scrollbar-width: thin`. |
| **WebKit** | Windows / Linux | Safari (эмуляция движка) | Обработка `100dvh` / `-webkit-fill-available`, перенос строк в японском тексте, рендеринг системных шрифтов. *(Примечание: не заменяет физический iPhone, реальные тесты вынесены в ручной чек-лист).* |

## 4. Темы оформления и доступность (Themes & Accessibility)

| Параметр | Режимы | Что проверяется |
| :--- | :--- | :--- |
| **Тема (Themes)** | `light`, `dark` | Контрастность текста по WCAG AA ($\ge 4.5:1$), видимость подсказок фуриганы, фоны модальных окон, цвета кнопок. |
| **Масштабирование** | `zoom_200`, `large_text` | Читаемость при увеличении страницы до 200%, отсутствие наложения текста поверх кнопок управления. |
| **Движение** | `prefers-reduced-motion` | Отключение резких анимаций смены карточек и индикаторов загрузки. |
| **Навигация** | `keyboard_only` | Полная доступность с клавиатуры: Tab, Shift+Tab, Enter, Space, Escape (фокусные рамки `:focus-visible`). |

## 5. Сетевые профили (Network Profiles)

| Профиль | Параметры (Пропускная способность / Задержка) | Ожидаемое поведение |
| :--- | :--- | :--- |
| `normal` | Неограниченно, RTT < 20 мс | Мгновенный отклик, плавная загрузка. |
| `slow_3g` | 400 Kbps down / 150 Kbps up, RTT 400 мс | Корректная индикация загрузки, отсутствие двойных отправок при повторном клике. |
| `offline` | 0 Kbps (сеть отключена) | PWA/Service Worker отдаёт кэшированные ресурсы, понятный баннер «Нет связи», сохранение ответов в локальную очередь. |
