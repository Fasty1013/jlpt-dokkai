# 🛡️ Анализ рисков и условий бесплатных тарифов ($0)

**Дата проверки по актуальной документации:** 2 ноября 2026 г.  
**Целевой бюджет:** **$0.00** (без кредитных карт, без платных подписок, без платных доменов).  
**Принцип работы:** Приложение **деградирует, а не платит**. При исчерпании любого лимита функция мягко отключается или уведомляет пользователя («временно недоступно»), но никогда не требует перехода на платный тариф.

---

## 1. Render Web Service (Free Tier)

| Параметр | Условие тарифа | Риск / Поведение | Архитектурное решение Dokkai |
| :--- | :--- | :--- | :--- |
| **Оперативная память (RAM)** | 512 MB | При превышении процесс мгновенно завершается (OOM Kill). | **Зафиксировано потребление 180 MB** (FastAPI + pykakasi). Запас ~332 MB. Словари и модели не дублируются в памяти; база вынесена в Neon. |
| **Процессор (CPU)** | ~0.1 vCPU (shared) | Медленный холодный старт (~50–60 с). | Клиент работает по архитектуре **PWA / Local-First**. Оболочка и закэшированные задания открываются мгновенно, показывая ненавязчивый индикатор: *«Сервер просыпается... (30–50 сек)»*. |
| **Бесплатные часы** | 750 часов / месяц на воркспейс | В месяце 720–744 часа. Если крутить пингер 24/7 и запустить второй тестовый сервис, часы исчерпаются до конца месяца, и сервис отключится. | **Keep-alive отключен по умолчанию.** Сервер засыпает через 15 минут простоя, экономя часы. 750 часов с запасом хватает на одного активного пользователя или группу учащихся в дневные часы. |
| **Домен** | `*.onrender.com` (бесплатно, HTTPS) | Нет собственного платного домена. | Используется бесплатный поддомен `*.onrender.com`. Полная поддержка HTTPS без покупки сертификатов. |

## 2. Neon Serverless PostgreSQL (Free Tier)

| Параметр | Условие тарифа | Риск / Поведение | Архитектурное решение Dokkai |
| :--- | :--- | :--- | :--- |
| **Дисковое пространство** | 1 GB на проект (расчётный лимит Dokkai: 0.5 GB) | Блокировка операций записи (INSERT/UPDATE) при превышении. | **Local-First изоляция данных:** сервер **никогда** не хранит ответы пользователей, заметки и избранное. Сервер хранит только профиль (~300 байт) и компактную историю решённых ID (~30 байт/запись). Вместимость: **более 140 000 пользователей** в пределах 500 MB. Мониторинг: алерт при 70% (350 MB), мягкий запрет новых регистраций при 85% (425 MB). |
| **Вычислительные часы (Compute)** | 100 CU-часов / месяц | При исчерпании проект приостанавливается до 1 числа след. месяца. | Автоматический **Scale-to-Zero через 5 минут** простоя. В спящем режиме потребляет 0 CU-часов. При типичной нагрузке расходуется <10 CU-часов в месяц. |
| **Сетевой трафик (Egress)** | 5 GB / месяц | Блокировка или замедление при превышении. | Фронтенд и статика отдаются из Render/PWA-кэша. Из Neon передаются только компактные JSON-ответы API (<2 KB на запрос). 5 GB = более 2.5 млн запросов к базе в месяц. |

## 3. Google Cloud OAuth 2.0 (OpenID Connect)

| Параметр | Условие тарифа | Риск / Поведение | Архитектурное решение Dokkai |
| :--- | :--- | :--- | :--- |
| **Оплата / Карта** | **$0, кредитная карта НЕ требуется** | Ошибочное подключение платных API (Maps, Cloud Run). | Используются **только базовые бесплатные OAuth-скоупы** (`openid`, `email`, `profile`). Платные API в проекте Google Cloud строго запрещены. |
| **Статус приложения** | "Testing" (100 тестовых email) или "In Production" (без платной верификации для базовых скоупов) | В режиме Testing токены живут 7 дней, вход только для добавленных email. | Для production-режима экран OAuth согласия публикуется в статус "In Production" со скоупами только базового профиля. Для таких скоупов ручная верификация Google и оплата **не требуются**. |
| **Локальная разработка** | Localhost redirect URI | Вход Google может требовать настроенного клиента. | В локальном окружении (`ENV=development`) автоматически доступен **Dev-Auth / Guest Login** без необходимости вводить реальные пароли или токены Google. |

## 4. Telegram Login Widget (@BotFather)

| Параметр | Условие тарифа | Риск / Поведение | Архитектурное решение Dokkai |
| :--- | :--- | :--- | :--- |
| **Стоимость** | **100% бесплатно навсегда** | Лимитов на количество входов нет. | Создаётся бесплатный бот через `@BotFather`. |
| **Привязка домена** | Требуется команда `/setdomain` у `@BotFather` | Виджет не работает на неавторизованном домене. | Человек привязывает домен `*.onrender.com` через `@BotFather`. Локально используется Dev-Auth / гостевой режим. |
| **Безопасность** | Валидация SHA-256 HMAC | Подделка сессии без токена бота невозможна. | Сервер проверяет криптографическую подпись данных Telegram с использованием `BOT_TOKEN`. |

## 6. Стратегия защиты от списаний (Hard Guarantee)

1. Ни в одном сервисе (Render, Neon, Google Cloud, GitHub) **НЕ вводится банковская карта**.
2. В коде исключены любые зависимости от платных API (платные OpenAI/Anthropic ключи заменены на локальный/бесплатный Ollama/HuggingFace или заготовленный сид-каталог).
3. При отказе или сне облачного бэкенда веб-интерфейс Dokkai продолжает работать в офлайн/гостевом режиме на основе локальной базы IndexedDB.
