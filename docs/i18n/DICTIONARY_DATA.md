# Данные всплывающего словаря по языкам (подитерация 3)

Принцип: **ничего не переводится «на лету» и не выдумывается** (CLAUDE.md п.6). Машинный перевод не используется.

| Язык UI | Что показывает попап при выделении слова | Источник |
| :-- | :-- | :-- |
| ru | Как раньше: словарь проекта (218 слов) → `GET /api/dictionary/lookup?q=` без `lang`; слова из `vocabulary` текста — их русский `translation` | БД / `dictionary_service.py` (контракт не менялся) |
| en | Глосса JMdict; если слова нет в индексе — ручная глосса | JMdict (EDRDG, CC BY-SA 4.0) + `app/data/dictionary_manual.txt` |
| uz | Ручная глосса; если её нет — **английская** (помечено «Перевода на узбекский нет — показан английский») | `app/data/dictionary_manual.txt` (+ JMdict en как запасной) |
| ja | Чтение и уровень JLPT; вместо толкования — «Японского толкования пока нет» | данных для японских определений нет |

Чтения: из словаря проекта или JMdict (поле `reading`), либо из `furigana` слова в тексте — никогда не выдумываются.
Склонённые формы (食べました) приводятся к словарной форме токенизатором Janome (уже зависимость проекта).
Частичные совпадения (`本当` → `本`) в не-русском пути **не используются** (дают неверную глоссу); русский путь сохраняет прежнее поведение (контракт).

## Ручной глоссарий (`app/data/dictionary_manual.txt`)
334 слова: все 218 слов словаря проекта + 116 слов из списков `vocabulary` активных текстов (покрытие проверяет `tools/dictionary_i18n_check.py`). Формат `слово|en|uz`. **Написан ассистентом, не вычитан носителем / @jlpt-expert** — в попапе помечен «Глоссарий проекта (не проверен носителем)». Убрать пометку можно после вычитки.

## JMdict (индекс сгенерирован)
Скачан релиз jmdict-simplified `3.6.2+20261109214828`, файл `jmdict-eng-common-3.6.2+20261109214828.json.zip` (1 445 502 байт, словарь от 2026-11-09). Собран `python tools/build_jmdict_index.py <json>` → `app/data/jmdict_en.json`: 22 650 статей, 34 891 форма, ≈3 МБ (в репозитории). Исходный архив в репозиторий не добавлялся. Это **частотные** слова (`common`): редкие/специальные слова (например 乖離) в индексе нет — для них остаётся ручная глосса. Для полного словаря можно собрать индекс из `jmdict-eng-*.json` (≈11,5 МБ архив) той же командой. Сервер подхватывает файл сам (`DOKKAI_JMDICT_INDEX` переопределяет путь). Для en JMdict приоритетнее ручной глоссы.
