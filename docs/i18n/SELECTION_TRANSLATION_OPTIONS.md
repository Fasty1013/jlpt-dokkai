# Перевод выделенного фрагмента: что есть сейчас и варианты источника

> Статус: **источник не выбран, реализация не начата** — ждём решения пользователя (CLAUDE.md п.6: переводы не выдумываются).

## Как устроено сейчас
- Выделение мышью в `#passage-content` (≤15 символов) или клик по `<ruby>` → `lookupAndShowWord` (`static/js/features/dictionary/popup_dict.js`).
- Порядок: (1) `activeText.vocabulary` (поле `translation`, русское, ~874 слов на 316 текстов, записано вручную в БД); (2) `GET /api/dictionary/lookup?q=` → `app/services/dictionary_service.py`: **218** записей `{word, reading, level, meaning}` с **русским** `meaning`, поиск по точному/подстрочному совпадению.
- Переводятся только слова/короткие фразы. Перевода **предложения/фрагмента** нет вообще; перевод всего текста — только `translation_ru` (русский, в разборе после сдачи).
- Данных на uz/en/ja в репозитории нет. В локальной (gitignored) `dokkai.db` есть таблица `translation_cache` с колонкой `translation_en` (492 записи, 222 с пометкой `provider=jmdict`, 270 — `none`), **ни одна строка кода её не использует**, происхождение и лицензия данных в репозитории не зафиксированы — использовать нельзя без выяснения.

| B. **JMdict + JMnedict/Tatoeba** для фраз | предложения en/… | Tatoeba CC BY 2.0 FR | примеры фраз | Нет перевода произвольного выделенного предложения |
| C. Собственные поля в БД (`translation_en/uz` в `vocabulary_json` и в `dictionary_service`) | только наши ~874+218 слов | своя | Контролируем качество, @jlpt-expert/пользователь вычитывают | Ручной труд, uz-переводы нужно писать/проверять; покрытие узкое |

| E. Гибрид: A/C для слов (проверенные), D только по явной кнопке «машинный перевод» с пометкой | слова + фразы | смешанная | Честно разделяет проверенное и машинное | Сложнее в реализации |

## Для японского («ja»)
Перевод = **японское толкование**, не обратный перевод. Источник: JMdict не даёт японских определений; нужен другой словарь (напр. Wiktionary ja / ``やさしい日本語`` вручную) — иначе для `ja` показываем только чтение (фуригана из токенизатора) и уровень. Требует решения.
