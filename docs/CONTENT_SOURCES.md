# Источники текстов из открытых источников

Задания с `origin = open_source` (файлы `content/open/n*.json`, черновики `content/open/src/`) построены на текстах под открытыми лицензиями или в общественном достоянии. Вопросы, варианты ответов, пояснения и перевод на русский написаны для этого проекта; фуригана — токенизатор janome (ручные исправления перечислены в `needs_manual_review` каждого задания).

Авторы — участники японской Википедии; история правок доступна по ссылке на статью (указана версия, с которой делалась адаптация).
- **Аодзора Бунко (общественное достояние).** Произведения авторов, умерших более 70 лет назад (срок охраны истёк). Благодарим вводчиков и корректоров Аодзоры (указаны в столбце «Версия»).
