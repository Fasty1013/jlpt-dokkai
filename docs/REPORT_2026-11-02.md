# 🥋 Отчёт о проделанной работе: Dokkai Master (2 ноября 2026 г.)

## 📌 Обзор проделанной работы за сегодня

Сегодня реализован масштабный комплекс улучшений образовательного тренажёра JLPT Dokkai Master:
1. **Непрерывный двухколоночный поток заданий («Задания» и «Решённые»):** карточная система (3 слота на профиль) с атомарной заменой задания на не виденное ранее (`pick_next`), режим повторного прохождения (`retry`), архив решённых с фильтрами («Все», «★ 100% Идеально», «С ошибками») и строгим Anti-Cheat контролем (блокировка утечек ответов до момента завершения).
2. **Мобильная навигация и защита от случайного выхода:** интеграция с History API (`popstate`), перехват жестов свайпа/кнопки «Назад» на смартфонах и переименование экранных кнопок на «← На главную».
3. **Постоянные правила проекта:** в `AGENTS.md` и `Agent.md` закреплены правила безопасности (Anti-Cheat, секреты в `.env`, запрет деструктивных команд, браузерному агенту разрешён только localhost).
4. **Этап 0: Планирование $0 автономного облака:**
   - Замеры фактической памяти процесса FastAPI + pykakasi (~180 MB RSS из 512 MB лимита Render).
   - Верификация условий бесплатных тарифов Render, Neon Postgres, Google Cloud OAuth, Telegram Login, GitHub Actions.
   - Пакет системной документации: `FREE_TIER_RISKS.md`, `CAPACITY.md`, `DATA_MAP.md`, `HUMAN_SETUP_CHECKLIST.md`, `PROGRESS.md`.
5. **Диагностика и устранение сбоев облачного деплоя на Render:**
   - Устранена ошибка сборки Docker (`Exit 1`): исключение конфигурации калибровки `difficulty_bands.json` из валидатора контента.
   - Устранена ошибка запуска контейнера (`Exit 3`): снятие `unique=True` с `content_hash` в `models.py`, кросс-БД миграция через `sqlalchemy.inspect`, эндпоинт `/api/health`.
   - Добавлена поддержка Neon Serverless Postgres (`psycopg2-binary`, автоисправление `postgres://` -> `postgresql://`).
6. **Официальные релизы на GitHub:** подготовлены и опубликованы три релиза: `v2.0.0`, `v2.0.1` и `v2.0.2`.
